# 🍄 Грибо.Net Browser

Браузер для общения с нейросетью **Лисичка.AI** 🦊

## ✨ Возможности

- 💬 **Текстовый чат** - пишите сообщения Лисичке
- 🎤 **Голосовой ввод** - говорите, приложение понимает речь
- 🔊 **Голосовой вывод** - AI отвечает голосом  
- 🌐 **Бесплатные облачные API** - никакой установки!
- 🛡️ **Приватно** - ваши данные в безопасности
- ⚡ **Быстро** - работает без задержек
- 🎨 **Красивый интерфейс** - темная тема с оранжевой тематикой 🍄

## 🎯 Как использовать

### 1️⃣ Текстовый чат
1. Введите сообщение в поле внизу
2. Нажмите кнопку "Отправить" или Enter
3. Лисичка ответит!

### 2️⃣ Голосовой ввод
1. Нажмите кнопку "🎤 Говорить"
2. Говорите в микрофон
3. Приложение распознает вашу речь
4. Автоматически отправит сообщение

### 3️⃣ Голосовой вывод
1. Нажмите "🔊 Голос: ВКЛ" чтобы включить
2. Лисичка будет отвечать голосом
3. Нажмите снова чтобы выключить

### 4️⃣ Настройки
1. Нажмите "⚙️ Настройки"
2. Выберите язык речи (Русский/English/Français)
3. Отрегулируйте скорость речи
4. Нажмите "Сохранить"

## 🐛 Решение проблем

### Голосовой ввод не работает
- ✅ Проверьте браузер (Chrome, Edge лучше всего)
- ✅ Проверьте микрофон (разрешите доступ)
- ✅ Убедитесь, что язык установлен правильно

### AI не отвечает
- ✅ Проверьте интернет соединение
- ✅ Откройте консоль браузера (F12) и проверьте ошибки
- ✅ Hugging Face API может быть перегружена - подождите

### Голосовой вывод не работает
- ✅ Проверьте громкость компьютера
- ✅ Убедитесь что голос включен ("🔊 Голос: ВКЛ")
- ✅ Проверьте, что речь установлена в настройках ОС
