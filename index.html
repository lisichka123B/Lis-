О программе

Грибо.Net Browser v1.0.0

Браузер для общения с нейросетью Лисичка.AI

Возможности:

  • 💬 Текстовый чат с AI
  • 🎤 Голосовой ввод (Web Speech API)
  • 🔊 Голосовой вывод
  • 🧠 Интеграция с Ollama для локального LLM
  • ⚡ Быстрые и приватные ответы

Требования:

  • Ollama установлена локально (http://localhost:11434)
  • Скачанная модель (mistral, llama2, neural-chat и т.д.)
  • Современный браузер с поддержкой Web Speech API

Разработано с ❤️ на Грибо.Net
